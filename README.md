# לוח בקרה — זיהוי הונאות בכרטיסי אשראי

דאשבורד אינטראקטיבי ב-Streamlit לניתוח נתוני הונאות בעסקאות כרטיסי אשראי, בעיצוב כהה בסגנון "חדר בקרה". מאפשר סינון, מיון וחקירה חזותית של הנתונים כדי לזהות אילו מאפייני עסקה הכי קשורים להונאה.

![style](https://img.shields.io/badge/UI-RTL%20Hebrew-blue) ![theme](https://img.shields.io/badge/theme-dark%20ops-black)

## הרצה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

הדאשבורד ייפתח בכתובת `http://localhost:8501`.

## הנתונים

`credit_card_fraud_10k.csv` — 10,000 עסקאות, 151 מהן הונאה (1.51%). כל שורה כוללת:

| עמודה | תיאור |
|---|---|
| `transaction_id` | מזהה עסקה |
| `amount` | סכום העסקה ($) |
| `transaction_hour` | שעת ביצוע העסקה (0–23) |
| `merchant_category` | קטגוריית העסק |
| `foreign_transaction` | האם עסקת חוץ (0/1) |
| `location_mismatch` | האם זוהתה אי-התאמת מיקום (0/1) |
| `device_trust_score` | ציון אמון המכשיר |
| `velocity_last_24h` | מספר עסקאות ב-24 השעות האחרונות |
| `cardholder_age` | גיל בעל הכרטיס |
| `is_fraud` | תיוג הונאה (0/1) |

## מה יש בדאשבורד

- **פילטרים** (בסיידבר, מימין): טווחי סכום/שעה/גיל/ציון אמון/קצב עסקאות, קטגוריית עסק, עסקת חוץ, אי-התאמת מיקום, סטטוס הונאה.
- **מדדי KPI**: סה"כ עסקאות, מספר הונאות, אחוז הונאה, סכום בסיכון — מתעדכנים לפי הפילטרים.
- **שיעור הונאה לפי קטגוריה / לפי שעה** — לאיתור מקטעים וזמנים בסיכון.
- **גרף קורלציה** — מדרג את כל המאפיינים לפי חוזק הקשר שלהם ל-`is_fraud`.
- **השוואת התפלגויות** בין עסקאות הונאה לתקינות לכל מאפיין מרכזי.
- **Scatter אינטראקטיבי** לבחירת שני מאפיינים וחקירת הקשר ביניהם.
- **טבלת נתונים** הניתנת למיון, עם הורדת התוצאה המסוננת כ-CSV.
